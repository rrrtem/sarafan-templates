Для ИИ-агентов

Исходники карточек 1080 × 1350 px, правила бренда и локальные ресурсы для создания публикаций Сарафана. Начните с инструкции и выберите нужный макет.

  • llms.txt — краткая точка входа со ссылками на материалы.
  • Инструкция для агентов — как скачать библиотеку, извлечь карточку, сохранить зависимости и проверить экспорт.
  • AGENTS.md — инструкции для работы в локальной папке.
  • Правила дизайн-системы — палитра, типографика, композиция и ограничения.
  • Машинный каталог файлов — пути, MIME-типы, размеры и SHA-256, селекторы шаблонов, CSS и публикации.

Эта страница и все ссылки доступны без JavaScript. Наличие llms.txt и AGENTS.md помогает обнаружить ресурсы, но не гарантирует автоматическое чтение всеми агентами. В задании можно явно указать ссылку на инструкцию.

Сохраняйте CSS выбранного макета и его локальные ресурсы. Карточки наследуют переменные --paper, --ink, --blue и reset размеров из catalog.css. Для самостоятельной карточки можно использовать токены CSS с совместимыми алиасами и локальный box-sizing: border-box. Подробный пример — в инструкции.

Токены и ресурсы

  • Токены JSON — цвета, сочетания, типографика, формат карточки и шрифты.
  • Токены CSS — переменные --sarafan-* и совместимые алиасы для готовых карточек.
  • Локальные шрифты CSS — объявления @font-face с путями от этого файла.
  • Происхождение и лицензии ассетов — сведения о файлах и лицензии Geist; права на CoFo Cinema1909 проектом не установлены.
  • Новые публикации — файлы posts/<id>/, регистрация и настройки кадрирования.

В шаблоне эксперта сохраните семейство Sarafan Expert Geist и локальный файл версии 1.6: замена меняет кириллицу и переносы. Перед снимком установите --card-scale: 1, размер 1080 × 1350 и дождитесь document.fonts.ready и загрузки изображений.

Скачать локальную копию

Сохраните download-kit.py и запустите Python 3 с URL каталога этой библиотеки. Подойдёт любой статический хостинг, в корне сайта или подпапке:

python3 download-kit.py https://example.org/sarafan/ --dest ./sarafan-local

Скрипт сохраняет структуру и проверяет контрольные суммы. Совпадающие файлы пропускаются, отличающиеся требуют флага --overwrite. Для отдельных путей или префиксов повторяйте --include; зависимости укажите самостоятельно. Синтаксис и пример частичного набора — в инструкции.

Полный каталог — корневой agent-manifest.json. Старый downloads/manifest.json содержит встроенные SVG/PNG и предназначен для интерфейса скачивания ассетов; его не нужно загружать в контекст первым. Архивы перечислены отдельно, устаревший sarafan-templates.zip исключён.
