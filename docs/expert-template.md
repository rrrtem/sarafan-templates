# Пост про эксперта · Бюро

Шаблон «Пост про эксперта» относится к разделу «Бюро» и представляет специалиста и его услуги. В исходном макете сохранена лента «Сарафан Бюро». В этом разделе также находятся полезные материалы о повседневной жизни во Франции.

Источник: [Figma · страница 327:209](https://www.figma.com/design/oEldVQIQ9PsRezkqg1rdzy/?node-id=327-209).
Пример: Катерина Штефан, коуч ICF / психолог. Формат каждой карточки — 1080 × 1350 px.

## Правила переноса

- Цвета карточек: оранжевый `#ff3c00`, кремовый `#fbeed2`; текст ленты `#553d3d`.
- Основной текст — Geist. Для этого исходника локально закреплён файл из официального выпуска [Geist 1.6.0](https://github.com/vercel/geist-font/releases/tag/1.6.0): `assets/expert-geist-v1.6.ttf`, CSS-семейство `Geist`. Этот единый вариативный файл используется во всех шаблонах. Более новая версия может изменить кириллицу и переносы текста. Лицензия — `assets/expert-geist-OFL.txt`.
- Крупные заголовки — 80 px / 100%, Medium 500; имя на обложке и подписи разделов — 40 px / 110%, SemiBold 600; описание на обложке — Light 300; основной текст «Обо мне» — Regular 400; подпись внизу — 25 px / 110%, Regular 400.
- Лента — EB Garamond Medium 500 и Medium Italic 500, 50 px / 86%.
- Основное левое поле — 65 px. Нижняя линия внутренних карточек — x 70.2588, y 1233.2217, ширина 939.482 px; подписи — y 1260.5889.
- Исходные SVG подключены локально с их оригинальными размерами. SVG маски и знаки не перерисованы.
- Скрытые под верхними фото исходные слои сохранены в тех же координатах, чтобы структура соответствовала макету.
- Ручные переносы строк из исходника сохранены. При замене текста проверяйте число строк и отсутствие переполнения; не уменьшайте кегль автоматически.

Разметка пяти карточек находится в `template-expert` внутри `index.html`, стили — в `expert.css`, ресурсы — в `assets/expert-*`.

Прямые ссылки: `#expert`, `#expert/2` … `#expert/5`. Экспорт: `exports/sarafan-expert-01.png` … `05.png`. Эталоны Figma для сравнения: `preview/expert-source-01.png` … `05.png`; они служат только для проверки и не используются в HTML-карточках.
