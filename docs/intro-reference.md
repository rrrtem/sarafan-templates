# Интро-пост «Сарафан» — образец стиля

Семь карточек из [Figma Page 11](https://www.figma.com/design/oEldVQIQ9PsRezkqg1rdzy/?node-id=344-3806) перенесены в HTML. Это готовый пост о проекте и пример его визуального языка, а не переиспользуемый шаблон с заменяемым содержанием.

В каталоге: «Общие» → «Интро-пост», отметка «Образец стиля». Прямая ссылка — `index.html#intro`; конкретная карточка — `#intro/1…7`. Образец не входит в счётчик шаблонов.

## Что брать из образца

- EB Garamond для редакционной типографики, с курсивными акцентами; Geist для ярлыков и рекламного текста; CoFo Cinema 1909 для надписи «Сарафан Салон».
- Палитра: оранжевый `#ff3c00`, кремовый `#fbeed2`, голубой `#a9c9df`, оливковый `#91945b`, розовый `#e19a9b`, коричневый `#553d3d`; тёмный текст Журнала — `#1e1e1e`.
- Овальные фото и круглые фотоколлажи, выразительные интервалы между блоками, небольшие фирменные значки, оранжевые ленты с краткими подписями.
- Разный ритм карточек: полноформатное фото, цветные редакционные карточки, коллаж, набор показателей и яркий финал.

Композиции служат ориентиром для новых постов. Их координаты не задают универсальные правила для любого содержания.

## Файлы

Разметка — блок `reference-intro` в `index.html`; стили — `intro.css`; изображения — `assets/intro-*`; описание образца и навигация — массив `references` в `catalog.js`. Все ресурсы локальные. Два сложных значка и два маскированных фотоколлажа экспортированы непосредственно из исходных слоёв Figma, без изменения рисунка. Текст остаётся текстом HTML.

Исходные шрифты находятся в `assets/`, включая CoFo Cinema 1909 и EB Garamond SemiBold Italic. Оригинальные размеры векторов сохранены. Для карточек 01 и 07 формат исходного фрейма 1081.333 × 1351.75 пропорционально приведён к 1080 × 1350.

PNG: `exports/sarafan-intro-01.png` … `sarafan-intro-07.png`. Контактный лист: `preview/intro-contact.png`. После правок HTML или CSS изображения необходимо экспортировать заново.
