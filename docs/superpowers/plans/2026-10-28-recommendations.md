# Рекомендации от человека — Implementation Plan

**Goal:** Добавить в «Журнал» три исходные обложки рекомендаций из Figma 386:13192.

**Architecture:** Статические карточки в #template-recommendations, отдельный recommendations.css, существующий просмотрщик catalog.js. Все изображения и оригинальная лента локальны. Текст остаётся редактируемым HTML.

**Tech Stack:** HTML, CSS, JavaScript; существующие Playwright, sharp, JSZip для экспорта.

## Ограничения

- Сохранить оригинальные 1080 × 1350, координаты, цвета, шрифты, переносы и два знака сноски.
- Порядок: места, бассейны, сувениры — слева направо в Figma.
- Портрет и лента — оригинальные ресурсы; полный SVG ленты включает обрезку исходной карточкой и имеет размер 82 × 606.
- Не менять другие карточки и текущие изменения пользователя.
