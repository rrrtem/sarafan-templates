# Доступ ИИ-агентов к опубликованной библиотеке

Дата: 28 октября 2026 года. Структура подтверждена владельцем в чате.

## Результат

Агент открывает любую основную страницу сайта, видит обычную HTML-ссылку
на инструкции и может скачать актуальные исходники для локальной вёрстки.
Серверный API, аккаунт, MCP и выполнение JavaScript для обнаружения материалов
не требуются. Публикация выполняется существующим статическим хостингом.

## Выбранный подход

1. `llms.txt` — короткий индекс материалов; `AGENTS.md` — правила работы;
   `docs/agent-guide.md` — практический маршрут; `agents.html` — статическая
   страница ссылок. Основные HTML-страницы ссылаются на эти материалы.
2. `agent-manifest.json` — каталог опубликованных файлов. `schemaVersion: 1`,
   `base: "./"`; `files` содержит `path`, `mediaType`, `bytes`, `sha256`.
   Пути разрешаются относительно каталога, содержащего manifest, а не домена.
   `templates` связывает шаблоны с HTML-селекторами, CSS и документацией.
   ZIP-комплекты находятся отдельно в `archives`; устаревший большой общий
   ZIP не является источником истины и не используется для скачивания.
3. `downloads/tokens.json`, `downloads/tokens.css`, `downloads/fonts.css` —
   переносимая дизайн-система. Источник цветов, сочетаний и типографики —
   `design-system-data.js`; определения шрифтов берутся из текущих CSS.
4. `scripts/download-kit.py` — Python 3, только стандартная библиотека.
   Получает manifest по URL сайта, сохраняет структуру каталогов, проверяет
   размер и SHA-256, отказывается от опасных путей. По умолчанию скачивает
   все `files`; `--include` выбирает конкретный файл или каталог.
5. `node scripts/build-agent-resources.cjs` пересобирает JSON/CSS и каталог
   после изменения исходников. Сам каталог не содержит собственный хеш.

## Ограничения

Формат карточек 1080 × 1350 px. Существующие макеты и правила бренда сохраняются.
Нет обещания, что каждый ИИ-клиент автоматически прочтёт инструкции: доступ
обеспечивается открытыми форматами и видимыми ссылками. У скрипта скачивания
нет зависимости от CORS; браузерный междоменный fetch не требуется.
Git сохраняет исходники и существующие рабочие материалы, исключая `.env`,
служебные файлы и генерируемые `sarafan-templates*.zip`.

## Проверка

Проверить воспроизводимость сборки, актуальность размеров и SHA-256,
разрешение ссылок под корнем и префиксом URL, видимость входа без JavaScript,
скачивание и локальный просмотр, отказы при неверном хеше и выходе из папки.
