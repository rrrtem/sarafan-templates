# Возможно ли выучить французский до суперуровня?

Готовая редакционная публикация на основе «Бюро · Полезная карусель». 7 карточек 1080 × 1350. Выбранная обложка: 1. Исходные шаблоны сохраняются.

Редактирование: `content.json`; сборка и проверка: `node scripts/build-bureau-posts.cjs` из корня библиотеки. HTML — самостоятельные карточки; PNG — рядом; `png.zip` — архив; `contact-sheet.png` — контактный лист; `layout-check.json` — проверка геометрии. `caption.txt` содержит описание и ссылки.

Описание уровней основано на FEI; упражнения и примеры жизненных задач — редакционная разработка, без обещаний сроков.

Проверено: 28.10.2026.
